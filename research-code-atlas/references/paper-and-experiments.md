# 论文与实验对照

无需另一个论文Skill或联网账户。若用户只给URL/标题且要求发现来源，按宿主已有工具查证；本工具不自动下载，已有本地文件优先。没有论文显示missing，不补造创新摘要。

paper命令按PDF真实页或MD/TXT页标记拆分；pypdf资源已包含，不依赖目标机单独下载pdftotext。扫描/缺文本页明确警告，不自动OCR。短引文须在对应页能找到，允许统一空白/引号与连字符换行；不能用印刷页码代替PDF页码。

读明确贡献→方法/算法/公式/变量→实验/附录/消融。区分论文作者主张与Agent解释。用关键词/变量/超参在指定项目rg定向搜，再读候选完整实现；不是按名称把方法强行映射到函数。

每个创新记录相对基线变化、机制、输入输出影响、关键配置、修改约束、paper_evidence和code_mappings。映射direct/inferred/not_found/conflict分别说明；有冲突保留双方原文，不擅改公式或源码。已实现但不在当前入口、仅测试中存在、配置关闭、训练/推理专用须分开，on_entry_path由闭包自动填。

实验值核对三方：论文值/页码、源码默认/行号、本次场景值/覆盖顺序/消费行。默认值不是最终值；环境变量/插值不求值。lr要追实际用途，只有print不能宣称传给优化器；mse名字不能当均方误差证据。消费者候选并不证明运行中采用。

适用清单：数据划分/增强/归一化、窗口/tokenizer；模型层数/维度/head/精度/冻结/权重；loss定义/reduction/系数/mask；batch/优化器/lr/scheduler/warmup/epoch/累积/裁剪；seed/设备/分布式；采样/checkpoint选择/评估指标/消融开关。项目没有的写not_applicable，不凑数。

有证据的运行成功也不等于论文级复现；本期没有runtime capture。fixture mini_paper只是测试材料，故意包含缩放×3对源码×2冲突、归一化direct、记忆库not_found，不是真实论文。
